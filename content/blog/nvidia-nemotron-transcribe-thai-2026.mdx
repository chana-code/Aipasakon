ถ้าคุณเคยลองให้ AI ถอดเสียงประชุมงานในไทย คุณน่าจะเจอปัญหาเดียวกัน คนไทยไม่ได้พูดไทยล้วน ประโยคเดียวมีทั้ง "เดี๋ยวขอ approve budget ก่อน deadline วันศุกร์" เครื่องมือถอดเสียงหลายตัวเจอแบบนี้แล้วสะกดคำอังกฤษเป็นภาษาไทยมั่ว ๆ หรือตัดทิ้งไปเลย

วันที่ 28 ตุลาคม 2026 Nvidia ปล่อย model ถอดเสียงตัวใหม่ชื่อ **Nemotron 3.5 Transcribe** แบบเปิดให้ดาวน์โหลดฟรี และในเอกสารของตัวเองระบุว่าภาษาไทยรองรับการพูดสลับภาษาด้วย บทความนี้สรุปจากสามแหล่ง คือบล็อกของ NVIDIA บน Hugging Face, model card (หน้าเอกสารประจำตัว model) และรายงานของ TechCrunch วันเดียวกัน ตัวเลขทุกตัวในบทความนี้เป็นตัวเลขที่ Nvidia รายงานเอง ยังไม่มีการทดสอบภาษาไทยจากคนนอก ส่วนที่เป็นความเห็นของเราเอง เราจะบอกไว้ชัด ๆ

## มันทำอะไรได้บ้าง

งานถอดเสียงในชีวิตจริงไม่ได้จบที่ "ได้ตัวหนังสือครบทุกคำ" คนที่เอาบันทึกประชุมไปใช้ต่ออยากรู้ด้วยว่าใครพูดอะไร อยากได้ฉบับแปล หรืออยากให้ศัพท์เฉพาะทางสะกดถูก Nvidia ออกแบบตัวนี้ให้ทำงานพวกนั้นได้ใน model ตัวเดียว ตามเอกสาร

- **ถอดเสียง 40 ภาษา** และ **แปลไป-กลับกับภาษาอังกฤษได้ 31 ภาษา**
- **แยกผู้พูด** บอกได้ว่าประโยคไหนใครพูด สูงสุด 8 คนต่อไฟล์ ฟีเจอร์นี้รองรับ 13 ภาษา ในวงการเรียกงานนี้ว่า diarization
- **รับไฟล์ยาวได้ถึงหนึ่งชั่วโมง** และบอกเวลาของแต่ละคำได้ (word-level timestamps)
- **ถามตอบจากเสียง** เช่นถามว่าในคลิปนี้ตกลงกันว่าอะไร แต่ข้อนี้ Nvidia ระบุว่าทดสอบมาแค่ภาษาอังกฤษ ภาษาอื่นอาจใช้ได้ไม่เสถียร

## ภาษาไทยอยู่ตรงไหน

ใน model card มีตารางภาษา แบ่งคุณภาพเป็นสามระดับ ระดับบนสุดคือ Leading (ดีที่สุดหรือเกือบดีที่สุดตั้งแต่แกะกล่อง) ถัดมาคือ Production-ready (คุณภาพระดับใช้งานจริง) และ Supported (รองรับ แต่อาจต้องปรับจูนเพิ่ม)

ภาษาไทยอยู่ระดับ **Production-ready** และได้เครื่องหมายครบทั้งสี่ช่อง คือถอดเสียง แปลกับภาษาอังกฤษ ถอดเสียงหลายผู้พูด และ **code-switching** ซึ่งก็คือการพูดสลับภาษาในประโยคเดียวกัน แบบที่คนไทยพูดกันในที่ทำงาน เทียบกับบางภาษาในยุโรปที่ได้ระดับเดียวกันแต่ไม่มีช่องแยกผู้พูด ภาษาไทยถือว่าได้ฟีเจอร์ครบ

ตัวเลขเดียวที่ Nvidia รายงานเฉพาะภาษาไทยคือผลบนชุดทดสอบ FLEURS ได้อัตราผิดระดับตัวอักษร (CER) 7.34% หมายความว่าโดยเฉลี่ยทุก 100 ตัวอักษร มีราว 7 ตัวที่ผิด ตกหล่น หรือเกินมา ภาษาไทยวัดเป็นตัวอักษรแทนคำ เพราะภาษาไทยเขียนติดกันไม่เว้นวรรคระหว่างคำ ตัวเลขนี้มาจากชุดทดสอบเสียงอ่านที่ค่อนข้างสะอาด เสียงประชุมจริงที่มีคนพูดแทรกกันและเสียงรบกวนมักทำให้ผลแย่กว่านี้ ข้อนี้เป็นความเห็นจากประสบการณ์ของเรา ไม่ใช่ตัวเลขของ Nvidia

## กลไก ทำไมมันสั่งได้ด้วยภาษาคน

เครื่องมือถอดเสียงรุ่นก่อนส่วนใหญ่ทำงานแบบเดียว ฟังเสียงแล้วพ่นตัวหนังสือออกมา จะปรับอะไรต้องไปแก้ที่การตั้งค่าหรือเทรนใหม่

Nemotron 3.5 Transcribe ต่างออกไป เพราะข้างในมันคือสองส่วนต่อกัน ส่วนแรกเป็นตัวฟังเสียง (audio encoder) ที่แปลงเสียงเป็นข้อมูลที่ model เข้าใจ และมีตัวจับลักษณะเสียงของแต่ละคนติดมาด้วย ส่วนที่สองเป็นโมเดลภาษา (LLM) ตัวเดียวกับที่ใช้ในแชทบอท รับทั้งข้อมูลเสียงและคำสั่งที่คุณพิมพ์ แล้วเขียนผลลัพธ์ออกมา ในวงการเรียก model แบบนี้ว่า speech-augmented language model

ผลคือคุณกำหนดรูปแบบผลลัพธ์ด้วยคำสั่งได้ เช่น

- ขอแบบคำต่อคำ เก็บ เอ่อ อ่า และคำพูดซ้ำไว้ครบ เหมาะกับงานวิจัยหรือตรวจสอบย้อนหลัง
- ขอแบบอ่านง่าย ตัดคำเติมและคำซ้ำทิ้ง เหมาะทำบันทึกประชุมหรือซับไตเติล
- บอกศัพท์ล่วงหน้า เช่นชื่อลูกค้า ชื่อสินค้า หรือคำย่อในวงการ แล้วกำชับว่าให้ใช้เฉพาะเมื่อได้ยินในเสียงจริง

ข้อสุดท้ายสำคัญมาก Nvidia ยกตัวอย่างจากงานถอดเสียงทางการแพทย์ แค่เขียนคำสั่งให้ระบุภาษาและตัวอักษรที่ต้องการให้ชัด อัตราผิดก็ลดจาก 30.8% เหลือ 23.8% และเมื่อเทรนเพิ่มด้วยข้อมูลเฉพาะทาง ลดลงเหลือ 11.8% บนชุดทดสอบเดียวกัน

อีกเรื่องที่ทำให้มันเร็ว model ทั้งตัวมีราว 30,000 ล้านพารามิเตอร์ แต่ใช้โครงสร้างแบบ mixture of experts คือแบ่งเป็นผู้เชี่ยวชาญย่อยหลายชุด แล้วเรียกใช้เฉพาะชุดที่เกี่ยวข้อง ในแต่ละขั้นจึงทำงานจริงราว 4,300 ล้านพารามิเตอร์ เปรียบเหมือนบริษัทที่มีพนักงานเยอะ แต่แต่ละงานเรียกแค่คนที่เกี่ยวข้องเข้าห้องประชุม

## ทำไม "เปิดให้โหลด" ถึงสำคัญกับบริษัทไทย

บริการถอดเสียงส่วนใหญ่ทำงานแบบเดียวกัน คุณอัปโหลดไฟล์เสียงขึ้นเซิร์ฟเวอร์ของผู้ให้บริการ แล้วรอรับตัวหนังสือกลับมา ถ้าไฟล์นั้นคือการประชุมเรื่องราคา สัญญา หรือข้อมูลลูกค้า หลายบริษัทไม่สบายใจจะส่งออกไปข้างนอก

model แบบ open-weight คือ Nvidia ปล่อยตัว model ให้ดาวน์โหลดไปติดตั้งบนเครื่องของคุณเอง ไฟล์เสียงไม่ต้องออกจากบริษัท model card ระบุว่าใช้ได้ทั้งเชิงพาณิชย์และไม่ใช่เชิงพาณิชย์ ภายใต้สัญญาอนุญาต OpenMDW-1.1 นอกจากนี้ Nvidia ยังปล่อยชุดข้อมูลเสียงสำหรับเทรน Granary v2 ซึ่งมีข้อมูลราว 463,000 ชั่วโมงใน 48 ภาษา พร้อมเครื่องมือให้บริษัทเอาไปปรับจูนกับศัพท์ในวงการของตัวเองได้

## ข้อจำกัดที่ต้องรู้ก่อน

- **ถอดได้เฉพาะไฟล์ที่อัดเสร็จแล้ว** ไม่ใช่ถอดสดระหว่างประชุม TechCrunch ชี้ข้อนี้เป็นจุดอ่อนหลัก
- **ติดตั้งเองต้องใช้เครื่องแรง** ตัวอย่างการติดตั้งใน model card ใช้การ์ดจอ H100 80 GB หนึ่งใบ ซึ่งเป็นการ์ดระดับศูนย์ข้อมูล รุ่นย่อขนาด (quantized) สำหรับเครื่องเล็กอย่าง DGX Spark หรือ RTX Spark Nvidia บอกว่า "เร็ว ๆ นี้"
- **ถามตอบจากเสียงทดสอบแค่ภาษาอังกฤษ** ถ้าถามเป็นภาษาไทย อย่าเพิ่งเชื่อผลมาก
- **ยังต้องตรวจเอง** Nvidia เขียนไว้ในบล็อกของตัวเองว่าให้สุ่มตรวจชื่อคน จุดเปลี่ยนผู้พูด และคำตอบเทียบกับเสียงจริง

## ถ้าคุณอยากลอง

**ถ้าคุณไม่ใช่สายเทคนิค** ลองผ่านหน้าเดโมบน Hugging Face ได้เลยที่ huggingface.co/spaces/nvidia/nemotron-transcribe อัปโหลดคลิปเสียงไทยสั้น ๆ ที่ไม่มีข้อมูลลับ เช่นคลิปที่คุณอัดเองพูดไทยปนอังกฤษสักนาที แล้วดูว่ามันสะกดคำอังกฤษถูกไหม จำไว้ว่าหน้าเดโมคือการส่งไฟล์ขึ้นเซิร์ฟเวอร์สาธารณะ อย่าใช้ไฟล์ประชุมจริงของบริษัท

**ถ้าบริษัทคุณมีทีมเทคนิค** มีสองทาง ทางแรกใช้ผ่านผู้ให้บริการที่ติดตั้งไว้แล้ว ซึ่ง Nvidia ระบุชื่อไว้คือ Baseten, DeepInfra และ Simplismart ทางที่สองติดตั้งเองด้วย vLLM ซึ่งเปิดเป็น API แบบเดียวกับของ OpenAI ทำให้ต่อเข้ากับโปรแกรมที่มีอยู่ได้ง่าย หรือถ้าคุณไม่ได้เขียนโค้ดเอง ส่งลิงก์ model card ให้ AI agent ที่รันโค้ดได้ เช่น Claude Code หรือ Codex แล้วสั่งให้มันติดตั้งบนเครื่องที่มีการ์ดจอพอ

**ความเห็นของเรา** สิ่งที่ควรทดสอบก่อนตัดสินใจไม่ใช่ตัวเลขบนตาราง แต่คือไฟล์ประชุมจริงสัก 3-5 ไฟล์ของคุณเอง ที่มีคนพูดแทรก มีศัพท์ในวงการ และมีชื่อลูกค้า แล้วนับเองว่าต้องแก้กี่จุด นั่นคือตัวเลขที่บอกได้จริงว่ามันช่วยประหยัดเวลาคุณแค่ไหน
