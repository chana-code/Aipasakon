ใครที่ใช้ Claude มาสักพักจะคุ้นกับคำถามเล็ก ๆ ที่โผล่ขึ้นมาก่อนเริ่มงานทุกครั้ง งานนี้พิมพ์ในแชตธรรมดาพอไหม หรือต้องเปิด Cowork หรือต้องไปที่ Claude Design ตั้งแต่วันที่ 16 กันยายน 2026 Anthropic ตัดคำถามนั้นทิ้ง แชตกับ Cowork รวมเป็นที่เดียว และเพิ่มของใหม่อีกสองตัวคือ Claude Docs กับ Claude Slides

บทความนี้แกะว่าเปลี่ยนอะไร ทำไมถึงเปลี่ยน กลไกเบื้องหลังคืออะไร และคนทำงานควรใช้มันต่างจากเดิมยังไง

## ประกาศนี้มีอะไรบ้าง

Anthropic เผยแพร่บล็อกชื่อ Claude Cowork and chat are now one Claude เมื่อวันที่ 16 กันยายน 2026 เนื้อหาหลักมีสามเรื่อง

เรื่องแรก แชตกับ Cowork รวมเป็น Claude ตัวเดียว คุณจะถามคำถามสั้น ๆ หรือโยนงานรายงานที่ต้องส่งเที่ยงวันให้ ก็พิมพ์ในที่เดียวกัน แล้ว Claude จะดูเองว่างานนั้นต้องใช้ความสามารถแบบไหน

เรื่องที่สอง มีของใหม่สองตัวคือ Claude Docs สำหรับเขียนเอกสาร และ Claude Slides สำหรับทำสไลด์ ทั้งคู่สั่งจากแชตไหนก็ได้

เรื่องที่สาม Claude Design ซึ่งเปิดตัวเมื่อเดือนเมษายนสำหรับงานออกแบบหน้าเว็บและต้นแบบ ตอนนี้ใช้ได้จากในบทสนทนาด้วย ส่วนคนที่ใช้ Claude Design แยกเป็นตัวของมันเอง ก็ยังใช้ได้เหมือนเดิม

## ทำไมเดิมถึงแยกกัน แล้วทำไมตอนนี้รวม

ต้องย้อนไปดูว่าแต่ละตัวทำหน้าที่ต่างกันยังไง

แชตธรรมดาคือการถามตอบ คุณพิมพ์ มันตอบ จบในหน้าจอนั้น ส่วน Cowork คือโหมดที่ Claude ทำงานแบบ agent คือรับเป้าหมายไปแล้วลงมือทำเองหลายขั้น เปิดไฟล์ ใช้เครื่องมือที่เชื่อมไว้ ทำชิ้นงานออกมา และทำต่อได้แม้คุณปิดโน้ตบุ๊กไปแล้ว บล็อกของ Anthropic เล่าว่าตั้งใจสร้าง Cowork เป็นที่แยกไว้สำหรับงานใหญ่ และสร้าง Design ไว้สำหรับงานภาพ

สิ่งที่ต้องเข้าใจคือ model ที่อยู่ข้างหลังเป็นตัวเดียวกัน ที่ต่างคือสิ่งที่ห่อมันไว้ ว่ามันเข้าถึงเครื่องมืออะไรได้ ทำงานต่อเนื่องได้นานแค่ไหน และผลงานไปอยู่ที่ไหน เรื่องนี้เราอธิบายละเอียดไว้ในบท [หน้าตาทั้งหลายของ AI ตัวเดียวกัน](/products/surfaces)

ปัญหาที่ Anthropic บอกว่าได้ยินจากผู้ใช้มีสองข้อ ข้อแรก ส่วนที่น่าหงุดหงิดคือต้องตัดสินใจว่างานนี้ควรไปอยู่ที่ไหน TechCrunch รายงานในทำนองเดียวกันว่าลูกค้ามักเลือกแท็บไม่ถูกกับงาน ข้อที่สอง งานที่เริ่มในที่หนึ่งไม่ตามไปอีกที่ คุยเรื่องรายงานในแชตมาครึ่งชั่วโมง พอย้ายไป Cowork ก็ต้องเล่าใหม่

คำตอบของ Anthropic คือเลิกให้ผู้ใช้เลือก บล็อกเขียนว่า Claude ตอนนี้ดูออกเองว่างานต้องการอะไร ความสามารถของ Cowork และ Design จึงเรียกใช้ได้จากทุกบทสนทนา พร้อมบริบท skills และ connectors ที่คุณตั้งไว้อยู่แล้ว

## Claude Docs และ Claude Slides ทำอะไรได้

Docs คือเอกสารที่คุณกับ Claude เขียนด้วยกัน ขอให้ร่างได้ แก้เองตรง ๆ ได้ หรือบอกให้ Claude แก้ให้ The Verge รายงานว่าเอกสารเริ่มต้นเป็นแบบส่วนตัว แล้วแชร์ให้คนอื่นเข้ามาแก้พร้อมกันได้คล้าย Google Docs และทั้งเพื่อนร่วมงานและ Claude ทิ้งคอมเมนต์ไว้ในเอกสารได้

Slides คือให้ Claude ร่างสไลด์ แล้วคุณแก้ต่อได้เอง นำเสนอจากใน Claude ได้เลย หรือดาวน์โหลดออกมาเป็นไฟล์ PowerPoint หรือ PDF

ทั้ง Docs, Slides และ Design ใช้หลักเดียวกันคือผลงานทุกชิ้นอยู่ที่ลิงก์เดียวที่แชร์ได้และเปิดบนมือถือได้ เลือกองค์ประกอบแล้วลากย้ายเองได้ หรือบอก Claude ว่าอยากให้เปลี่ยนอะไร TechCrunch เสริมว่าสั่งให้เริ่มทำเอกสารบนคอมพิวเตอร์ แล้วเช็กความคืบหน้าจากแอปมือถือได้

ทั้งสามตัวยังเป็นเวอร์ชันทดลอง (beta) และใช้ได้เฉพาะแพ็กเกจแบบเสียเงิน

## ตัวอย่างที่ Anthropic ใช้อธิบาย

บล็อกยกสถานการณ์ที่คนทำงานออฟฟิศน่าจะเห็นภาพชัด รายงานประจำสัปดาห์ต้องส่งเที่ยง ก่อนออกจากบ้านคุณถาม Claude ว่าสัปดาห์ที่แล้วงานในไปป์ไลน์ขยับไปยังไงบ้าง แล้วสั่งต่อว่าให้เขียนแบบที่ทำประจำ ชี้จุดที่หลุดกำหนด และสรุปไฮไลต์เป็นสไลด์ห้าหน้าสำหรับประชุมผู้บริหาร ถ้ามีอะไรไม่ชัด Claude จะถามกลับ

ระหว่างเดินทางคุณเช็กความคืบหน้าจากมือถือได้ พอถึงโต๊ะ รายงานรออยู่ในรูปเอกสารที่มีโน้ตของเพื่อนร่วมทีม และสไลด์พร้อมเปิดแก้และดาวน์โหลดเป็น PowerPoint เพราะทั้งสองชิ้นมาจากบทสนทนาเดียวกัน สไลด์จึงตรงกับรายงานอยู่แล้ว คุณแก้บรรทัดหนึ่งเอง ทิ้งคอมเมนต์ให้ Claude แก้สไลด์หน้าหนึ่ง แล้วแชร์ออกไป และถ้าตั้งเวลาให้ทำทุกวันจันทร์ Claude จะเริ่มทำรายงานเองโดยไม่ต้องสั่ง

จุดที่ควรสังเกตในตัวอย่างนี้ไม่ใช่ความสะดวก แต่คือคำว่ามาจากบทสนทนาเดียวกัน ของที่ทำให้ AI ทำงานได้ดีคือบริบท ถ้าบริบทอยู่ที่เดียว ชิ้นงานหลายชิ้นก็สอดคล้องกันเอง ถ้าบริบทกระจายอยู่หลายที่ คุณคือคนที่ต้องคอยเล่าซ้ำและคอยเช็กว่าตัวเลขในสไลด์ตรงกับในรายงาน

## ใครคุมใคร

เมื่อ AI ลงมือทำงานได้เองมากขึ้น คำถามที่ตามมาคือมันจะทำอะไรไปโดยไม่ถามหรือเปล่า

บล็อกระบุว่าค่าเริ่มต้นคือ Claude จะถามก่อนลงมือทำ action ต่าง ๆ ถ้าคุณอยากให้มันทำต่อไปเรื่อย ๆ แล้วเรียกคุณเฉพาะตอนที่มีอะไรต้องดูใกล้ ๆ ก็เปิดตั้งค่านั้นได้ Anthropic ใช้คำว่าคุณยังเป็นคนตัดสินใจสุดท้าย

ข้อแนะนำของเราคือเริ่มจากค่าเริ่มต้นไปก่อน ใช้ไปสักพักจนรู้ว่างานแบบไหนที่มันทำถูกสม่ำเสมอ แล้วค่อยปล่อยให้ทำเองเฉพาะงานประเภทนั้น

## ใครได้ใช้ และเมื่อไร

อัปเดตนี้ทยอยปล่อยให้แพ็กเกจ Pro และ Max ก่อน ในแอป Claude บนเว็บ เดสก์ท็อป และมือถือ ภายในไม่กี่สัปดาห์ข้างหน้า ทั้งผู้ใช้เดิมและผู้ใช้ใหม่ ไม่ต้องกดเปิดอะไร แพ็กเกจ Team และ Free จะตามมา ส่วนองค์กรที่ใช้ Enterprise ผู้ดูแลระบบจะได้รับแจ้งล่วงหน้าอย่างน้อย 30 วันก่อนมีอะไรเปลี่ยน และผู้ดูแลเป็นคนเลือกว่าจะเปิด Docs, Slides และ Design เมื่อไร

คนที่ใช้ Cowork อยู่แล้ว ของเดิมอยู่ครบ ทั้งแชต โปรเจกต์ artifacts connectors และ skills ส่วนคนที่ใช้แต่แชต ก็ใช้แบบเดิมต่อไปได้โดยไม่ต้องเปลี่ยนอะไร

ประกาศไม่ได้ระบุกำหนดการแยกตามประเทศ ถ้าบัญชีของคุณยังไม่เห็นหน้าตาใหม่ ให้เข้าใจว่าเป็นการทยอยปล่อย ไม่ใช่ว่าตกหล่น

## ภาพใหญ่ของการแข่งขัน

The Verge ตั้งข้อสังเกตว่าจุดได้เปรียบของ Google คือ AI ผูกอยู่กับชุดโปรแกรมทำงานที่คนใช้อยู่แล้ว ต้นปีนี้ Google ขยายบทบาทของ Gemini ใน Google Docs, Sheets และ Slides ทั้งหน้าต่างแชตในเอกสาร การสร้างและแก้เอกสารทั้งฉบับ และการสร้างสไลด์ การที่ Claude มี Docs และ Slides ของตัวเองจึงเป็นการปิดช่องว่างนั้น และให้เหตุผลน้อยลงที่ผู้ใช้จะต้องออกจากแชตไปเปิดโปรแกรมอื่น TechCrunch ยังระบุว่าอัปเดตนี้มาหลังจาก Anthropic เพิ่งยกระดับระบบความจำของ Cowork ที่ช่วยให้ Claude จำบริบทของผู้ใช้ข้ามบทสนทนาได้

ทิศทางที่อ่านได้จากทั้งสองค่ายตรงกัน คือ AI กำลังเปลี่ยนจากหน้าต่างที่คุณไปถามคำถาม ไปเป็นที่ที่งานเกิดขึ้นและจบลงจริง

## คนทำงานควรใช้ต่างจากเดิมยังไง

ข้อแรก เลิกคิดว่าต้องเลือกเครื่องมือก่อนเริ่ม ให้คิดว่าอยากได้ผลลัพธ์หน้าตาแบบไหน แล้วบอกให้ครบในคำสั่งเดียว ทั้งเนื้อหา รูปแบบ และปลายทาง เช่น สรุปยอดขายไตรมาสนี้เทียบไตรมาสก่อน ทำเป็นเอกสารหนึ่งหน้าสำหรับหัวหน้า และสไลด์สามหน้าสำหรับประชุมทีม ยิ่งบอกปลายทางชัด ระบบยิ่งเลือกความสามารถที่ใช้ได้ถูก

ข้อสอง ทำงานที่เกี่ยวข้องกันในบทสนทนาเดียวกัน เพราะนั่นคือสิ่งที่ทำให้เอกสารกับสไลด์สอดคล้องกันโดยไม่ต้องเช็กเอง

ข้อสาม ของที่ยังเป็น beta ตรวจก่อนส่งทุกครั้ง โดยเฉพาะตัวเลข ชื่อคน และข้อสรุปที่จะไปถึงผู้บริหาร การที่มันทำเสร็จเร็วไม่ได้แปลว่ามันถูก

ข้อสี่ ก่อนแชร์ลิงก์ออกไป ดูให้แน่ว่าแชร์ให้ใครและเขาแก้ได้หรือแค่ดู เอกสารที่อยู่ในลิงก์เดียวสะดวกกับทีม แต่ก็สะดวกกับคนที่ไม่ควรเห็นเหมือนกัน
