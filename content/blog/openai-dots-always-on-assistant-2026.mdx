ถ้าคุณใช้ ChatGPT มาสักพัก คุณคงชินกับจังหวะเดิม คุณพิมพ์ถาม มันตอบ คุณไม่พิมพ์ มันก็เงียบ ปีนี้บริษัท AI หลายเจ้ากำลังพยายามเปลี่ยนจังหวะนี้ ด้วยผู้ช่วยที่ทำงานต่อเบื้องหลังแม้คุณไม่ได้สั่ง Instinct สตาร์ทอัพที่ดังขึ้นมาข้ามคืน Muse ของ Meta และ dots ของ OpenAI ล้วนเดินทางนี้

ข้อมูลในบทความนี้มาจากรายงานของ TechCrunch วันที่ 26 ตุลาคม 2026 เขียนโดย Tim Fernholz ซึ่งสรุปการขึ้นเวทีของ Alexander Embiricos หัวหน้าทีมผลิตภัณฑ์องค์กรของ OpenAI ที่งาน TechCrunch Disrupt เดือนนี้ พร้อมผลการทดลองใช้ของทีม TechCrunch เอง ส่วนที่เป็นความเห็นของเราเอง เราจะบอกไว้ชัด ๆ

## dots คืออะไร

OpenAI เปิดตัว dots ในงานสำหรับนักพัฒนาช่วงปลายเดือนกันยายน มันอยู่ในแอป ChatGPT ทั้งบนคอมพิวเตอร์และมือถือ เปิดให้สมาชิกระดับ Pro ขึ้นไป ซึ่งแพ็กเกจเริ่มที่เดือนละ 100 ดอลลาร์

หลังจากคุณต่อมันเข้ากับปฏิทิน อีเมล คอมพิวเตอร์ และเครื่องมืออื่น ๆ มันจะพยายามช่วยงานคุณให้เสร็จ จุดที่ต่างจากแชทปกติมีสองข้อ ข้อแรก มันไม่รอคำสั่ง ข้อสอง มันคุยกับคุณเป็นบทสนทนาเดียวยาวต่อเนื่อง ไม่ใช่แยกเป็นแชทใหม่หลายสิบห้อง Embiricos อธิบายว่าพอทีมวางมันเป็นตัวตนหนึ่งตัวที่คุยกับคุณในบทสนทนาเดียว คนจะเข้าใจวิธีใช้ได้เองโดยไม่ต้องสอน เขามองว่านี่คือเหตุผลที่ผู้ช่วยของหลายบริษัทช่วงนี้มีหน้าตาเป็นตัวการ์ตูนคล้าย ๆ กัน ส่วนชื่อ dots มาจากช่องว่างในโลโก้ของ OpenAI

## มันมาจากเครื่องมือเขียนโค้ด

Embiricos บอกว่าสิ่งที่ dots ทำ ส่วนใหญ่ทำได้อยู่แล้วด้วย Codex แอปเขียนโค้ดของ OpenAI ที่ออกต้นปีนี้ แต่ต้องตั้งค่าและคอยประคองเองเยอะ เขาเล่าว่าเคยดีใจตอนภรรยาเริ่มเปิดคอมทิ้งไว้ทั้งคืน เพื่อให้ agent ทำงานต่อได้ งานของทีมผลิตภัณฑ์จึงไม่ใช่การสร้างเทคโนโลยีใหม่ แต่คือการห่อความสามารถเดิมของ model ให้คนทั่วไปใช้ได้ง่าย เป็นทางเดียวกับที่ OpenAI แยก ChatGPT Work ออกมาจากเครื่องมือเขียนโค้ดสำหรับวิศวกร

ข้อสังเกตของเรา เรื่องนี้ตอบคำถามที่หลายคนสงสัยว่าทำไมบริษัท AI ทุ่มกับเครื่องมือเขียนโค้ดนัก เพราะเครื่องมือพวกนั้นคือห้องทดลองของความสามารถแบบ agent คือ AI ที่ลงมือทำงานหลายขั้นเองได้ พอมันนิ่งพอ ความสามารถเดียวกันก็ถูกห่อใหม่มาให้คนทำงานทั่วไป

## กลไก proactive research ทำงานยังไง

หัวใจของผู้ช่วยแบบนี้คือมันไม่ต้องรอ prompt หรือข้อความสั่งงานจากคุณ Embiricos อธิบายฟีเจอร์ที่ทีมเรียกว่า proactive research ไว้แบบนี้ ทุกช่วงเวลาหนึ่ง มันจะทบทวนสามอย่าง

1. สิ่งที่มันรู้เกี่ยวกับตัวคุณ
2. บทสนทนาที่คุณกับมันคุยกันมา
3. ข้อมูลและเครื่องมือที่คุณเปิดสิทธิ์ให้มันเข้าถึง

จากนั้นมันจะไปค้นต่อเองว่าทำอะไรได้อีกเพื่อช่วยคุณ แล้วเสนอกลับมา

เทียบให้เห็นภาพ แชทปกติเหมือนพนักงานที่นั่งรอให้คุณเดินมาสั่งงาน dots พยายามเป็นเลขาที่เปิดตารางงานของคุณทุกเช้า เห็นว่าบ่ายนี้มีประชุมชนกันสองนัด แล้วเดินมาถามก่อนว่าจะย้ายนัดไหน เปรียบเทียบนี้ใช้ได้แค่บางส่วน เลขาคนจริงรู้ว่าเรื่องไหนควรเตือนตอนไหน ส่วน dots ยังเรียนรู้เรื่องจังหวะอยู่ อย่างที่จะเห็นในหัวข้อถัดไป

Embiricos เล่าตัวอย่างจากวิศวกรสตาร์ทอัพส่งของด้วยโดรนคนหนึ่ง ระบบของบริษัทล่ม และกว่าวิศวกรคนนั้นจะรู้ตัว dots ของเขาก็สังเกตเห็น วิเคราะห์สาเหตุ และมาเสนอข้อมูลที่ช่วยแก้ปัญหาแล้ว

อีกด้านของกลไกนี้ที่ TechCrunch ชี้ไว้ตรง ๆ ผู้ช่วยที่คิดเองตลอดหมายถึงการใช้ token มากขึ้น token คือหน่วยที่ model ใช้นับข้อความที่อ่านและเขียน ยิ่ง model คิดเยอะ ยิ่งใช้มาก สำหรับ OpenAI นี่คือการใช้งานที่เพิ่มขึ้น สำหรับคุณคือผู้ช่วยที่กระตือรือร้นขึ้น

## ทดลองจริงแล้วเป็นยังไง

ทีม TechCrunch ทดลองใช้แล้วพบว่ามันคิดล่วงหน้าได้จริงและมีประโยชน์บ่อย ๆ แต่ยังไม่ถึงจุดที่ควรเป็น มันเตือนเรื่องนัดที่ชนกันและเส้นตายที่ใกล้เข้ามา แต่ไม่ได้เตือนทันเวลาเสมอ

Embiricos ยอมรับเองว่าตอนพัฒนาช่วงแรก dots ของเขาเตือนนัดที่ชนกันล่วงหน้าแค่ 3 นาที เขาคาดว่าเรื่องจังหวะจะดีขึ้นเรื่อย ๆ และยืนยันว่าการคิดล่วงหน้าคือแกนของผลิตภัณฑ์นี้

ช่วงเปิดตัว OpenAI ยังโดนติว่าผู้ช่วยขออนุญาตบ่อยเกินไป Embiricos บอกว่าทีมตั้งค่าเริ่มต้นไว้ระมัดระวังมากโดยตั้งใจ และรู้อยู่แล้วว่าจะโดนติ แต่คิดว่าค่อยปรับทีหลังได้

## ราคาที่ต้องจ่ายคือข้อมูลของคุณ

ผู้ช่วยแบบนี้ยิ่งรู้เรื่องคุณมาก ยิ่งช่วยได้มาก นี่คือความตึงที่ agent ทุกตัวต้องเจอ คู่แข่งอย่าง Muse ของ Meta โดนวิจารณ์เรื่องการสร้างโปรไฟล์ของครอบครัวและเพื่อนผู้ใช้ เพื่อเอาไปเดาว่าคุณน่าจะอยากไปร้านอาหารแบบไหนกับเพื่อนคนไหน ซึ่งอาจมีค่ามหาศาลกับธุรกิจโฆษณาของ Meta ด้วย

เมื่อถูกถามว่า dots เก็บข้อมูลแบบเดียวกันไหม Embiricos ตอบว่าใช่ และอธิบายถึง proactive research ที่เล่าไปข้างบน TechCrunch ตั้งข้อสังเกตว่าเป็นเรื่องยากที่จะแยกว่าข้อมูลส่วนไหนผู้ช่วยต้องใช้จริง ส่วนไหนเป็นประโยชน์ของบริษัทแม่ และยกตัวอย่าง Hark สตาร์ทอัพที่ทำผู้ช่วยส่วนตัวเหมือนกัน ซึ่งประกาศชัดว่าไม่ได้เก็บข้อมูลไปหนุนธุรกิจโฆษณาแบบที่ OpenAI และ Meta ทำ

ฝั่ง OpenAI บอกว่า dots ใช้การตั้งค่าความเป็นส่วนตัวชุดเดียวกับ ChatGPT

- ปิดการเทรน model ได้ คือไม่ให้ OpenAI เอาบทสนทนาของคุณไปปรับปรุง AI
- เลือกได้ว่าจะให้มันเข้าถึงอะไรในคอมพิวเตอร์ และเข้าถึงแบบไหน

แต่ผู้สื่อข่าวชี้ว่าการตั้งค่าเหล่านี้ยังหยาบ และแอปค่อนข้างเรียกร้อง ตัวอย่างชัดที่สุดคือมันไม่ยอมรับสิทธิ์แบบอ่านอย่างเดียวสำหรับไดรฟ์บนคลาวด์ ถ้าจะให้มันเข้าไดรฟ์ คุณต้องให้สิทธิ์มากกว่าแค่อ่าน Embiricos ยอมรับว่าต้องสร้างการตั้งค่าที่ละเอียดกว่านี้มาก และชี้ว่าอีกด้านของเรื่องคือความฉลาดและวิจารณญาณของตัว model เอง

## เมื่อ agent ต้องคุยกับโลกจริง

คำถามใหญ่อีกข้อคือ agent จะขยายไปใช้กันทั้งโลกได้ไหม ตอนที่มีคนใช้ไม่กี่คนมันดูสนุก มีเรื่องเล่าว่า agent จองร้านที่จองยากได้ แต่ธุรกิจหลายแห่งไม่อยากรับมือกับ agent และอาจยังไม่พร้อมด้วย ตัว Embiricos เองยังมีผู้ช่วยที่เป็นคนจริง เพราะพาร์ทเนอร์ของ OpenAI อยากคุยกับคน และเขาบอกว่าตัวเองไม่ตั้งใจจะประชุมกับ agent ของใครเลย

เขายังบอกใบ้ว่า OpenAI กำลังคุยลึกกับบริษัทรับชำระเงินหลายแห่ง ถ้าวันหนึ่งผู้ช่วยแบบนี้จ่ายเงินแทนคุณได้ นั่นจะเป็นก้าวใหม่ของ OpenAI แต่ก็เป็นการขอความไว้ใจที่ใหญ่มากจากผู้ใช้ ผู้สื่อข่าวเขียนไว้ว่าแค่ให้เข้าอีเมลก็รู้สึกว่าขอเยอะแล้ว บัญชีธนาคารยังเป็นเขตห้ามเข้า อย่างน้อยก็ตอนนี้

## ถ้าคุณกำลังคิดจะใช้ผู้ช่วยแบบนี้

ส่วนนี้เป็นความเห็นของเรา ไม่ได้มาจากบทความต้นทาง

ผู้ช่วยที่ทำงานเองเบื้องหลังมีประโยชน์จริงกับงานที่ซ้ำและตามยาก เช่น ตามนัด ตามเส้นตาย สรุปอีเมลค้าง แต่มันเปลี่ยนคำถามจาก AI ตอบถูกไหม เป็น AI ควรเห็นอะไรบ้าง และควรทำอะไรได้เองบ้าง ก่อนเปิดสิทธิ์ ลองแยกให้ชัดสามเรื่อง

1. **ข้อมูลที่ให้เห็นได้** เช่น ปฏิทินงาน ซึ่งพลาดแล้วเสียหายน้อย
2. **ข้อมูลที่ไม่ควรให้เห็น** เช่น อีเมลที่มีข้อมูลลูกค้า สัญญา หรือเรื่องเงิน โดยเฉพาะข้อมูลของบริษัท ควรเช็กนโยบายของที่ทำงานก่อน
3. **งานที่ให้เสนอได้แต่คุณต้องกดยืนยันเอง** เช่น ย้ายนัด หรือตอบอีเมลออกไปหาคนนอก

เริ่มจากกลุ่มแรก ดูว่ามันช่วยได้จริงแค่ไหน แล้วค่อยขยายทีละขั้น ดีกว่าเปิดทุกอย่างตั้งแต่วันแรกแล้วมานั่งไล่ปิดทีหลัง
