บริษัท AI ใหญ่ทุกเจ้ากำลังขายภาพเดียวกัน ผู้ช่วย AI ที่ออกไปทำงานบนเว็บแทนคุณ จองร้านอาหาร เคลียร์อีเมล ซื้อรองเท้า แต่ช่วงสัปดาห์ที่ผ่านมา ภาพนั้นเจอปัญหาที่ไม่ได้มาจากความเก่งของ AI เลย ปัญหาคือเว็บดังหลายแห่งไม่ยอมให้มันเข้า ข้อมูลในบทความนี้มาจากรายงานของ The Verge วันที่ 16 ตุลาคม 2026 เขียนโดย Emma Roth

บทความนี้สรุปว่าใครปิดประตูใส่ AI agent บ้าง แต่ละเจ้าให้เหตุผลว่าอะไร ฝั่งบริษัท AI ตอบโต้ยังไง และทั้งหมดนี้แปลว่าอะไรสำหรับคนที่กำลังจะใช้ agent กับคนที่มีร้านหรือเว็บของตัวเอง

## AI agent คืออะไร และมันใช้เว็บยังไง

ก่อนจะไปถึงข่าว ต้องเห็นภาพก่อนว่า AI agent ต่างจากแชทบอทธรรมดาตรงไหน แชทบอทตอบคำถามจากสิ่งที่มันรู้หรือค้นมาได้ ส่วน agent คือ AI ที่ได้รับสิทธิ์ให้ลงมือทำ มันเปิดเว็บ อ่านหน้าจอ กดปุ่ม กรอกฟอร์ม และทำงานหลายขั้นต่อกันจนจบ โดยคุณสั่งแค่เป้าหมาย เช่น หาตั๋วเที่ยวบินที่ถูกที่สุดแล้วจองให้

ประเด็นสำคัญคือ ในสายตาของเว็บไซต์ agent ไม่ใช่คน มันคือโปรแกรมที่เข้ามากดหน้าเว็บแทนคน และเว็บส่วนใหญ่ถูกสร้างมาให้คนใช้ ไม่ได้ออกแบบมาต้อนรับโปรแกรม

## ใครปิดประตูบ้าง

The Verge รายงานว่าในช่วงหลายสัปดาห์ที่ผ่านมา ผู้ใช้ agent หลายตัว ทั้ง Muse ของ Meta, Grok ของ xAI, Dots ของ OpenAI และ agent ของบริษัท Instinct รายงานว่าโดนบล็อกไม่ให้ทำงานบนเว็บใหญ่หลายแห่ง ตัวอย่างที่ชัดเจนมีดังนี้

- **Yelp** บอกกับ TechCrunch ว่าอนุญาตเฉพาะ AI agent ที่จ่ายเงินเข้าโครงการขอใช้ข้อมูลของ Yelp เท่านั้น
- **Delta Air Lines** สายการบินใหญ่ของสหรัฐ ไม่ให้ agent จองตั๋วแทนผู้ใช้
- **JPMorgan Chase** และ **Charles Schwab** ยืนยันว่าบล็อก AI agent ไม่ให้เข้าบัญชีลูกค้า ด้วยเหตุผลด้านความปลอดภัย
- ผู้ใช้บางคนบอกว่าเว็บที่เคยใช้กับ agent ได้ อย่าง Cars.com และ Amtrak ตอนนี้เข้าไม่ได้แล้ว ซึ่งชี้ว่าอาจมีบริษัทอื่นที่บล็อกอยู่เงียบ ๆ โดยไม่ประกาศ

และเจ้าที่หนักที่สุดคือ **Amazon** ซึ่ง The Verge รายงานว่าบอกว่าการเข้าเว็บอย่างต่อเนื่องของ Muse ละเมิดนโยบายของเว็บ และมีรายงานว่า Grok, agent ของ Instinct และ Dots ก็ใช้ Amazon ไม่ได้เช่นกัน

## เรื่องนี้เริ่มก่อนหน้านี้แล้ว คดี Amazon กับ Perplexity

Amazon ไม่ใช่เพิ่งเริ่มสู้ ปีที่แล้ว Amazon แบนฟีเจอร์ซื้อของด้วย agent ของ Perplexity และฟ้องร้องบริษัทนี้ Amazon อ้างว่าขอให้ Perplexity หยุดหลายครั้งแล้ว และบอกว่าบริษัทภายนอกที่ซื้อของแทนลูกค้า ควรทำอย่างเปิดเผยและเคารพการตัดสินใจของผู้ให้บริการว่าจะร่วมด้วยหรือไม่

Perplexity ตอบกลับว่า เหตุผลจริงที่ Amazon ไม่อยากให้ agent เดินในเว็บ คือ agent ไม่ใช่คนที่จะมองเห็นโฆษณา ซึ่งเป็นรายได้ก้อนใหญ่ของ Amazon และเปรียบ agent ว่าเป็นส่วนขยายของตัวผู้ใช้ เหมือนคุณจ้างผู้ช่วยไปทำธุระแทน

เส้นทางในศาลยังไม่จบ ศาลเคยสั่งให้ Perplexity หยุดให้ agent ซื้อของบน Amazon แต่ศาลอุทธรณ์กลับคำสั่งนั้นเมื่อเดือนสิงหาคม และ Amazon ยื่นคำฟ้องฉบับแก้ไขแล้ว

## ทำไมเว็บถึงไม่อยากให้ agent เข้า

ถ้ารวมเหตุผลจากรายงานนี้ จะเห็นว่าไม่ได้มีเหตุผลเดียว แต่มีอย่างน้อยสี่แบบ และแต่ละแบบแก้ด้วยวิธีต่างกัน

**หนึ่ง ความปลอดภัย** ธนาคารและบริษัทการเงินอย่าง JPMorgan Chase กับ Charles Schwab ยกเหตุผลนี้ตรง ๆ การปล่อยโปรแกรมที่ถือสิทธิ์เข้าบัญชีลูกค้าไปกดปุ่มเอง เปิดช่องให้เกิดความเสียหายที่ตรวจสอบยากว่าใครสั่ง

**สอง รายได้จากสายตาคน** ข้อกล่าวหาของ Perplexity ต่อ Amazon สะท้อนจุดนี้ เว็บที่หาเงินจากโฆษณาหรือการวางสินค้าให้คนเห็น เสียประโยชน์ถ้าผู้มาเยือนเป็นโปรแกรมที่ไม่มองโฆษณา

**สาม ข้อมูลคือสินค้า** Yelp ไม่ได้ปิดตาย แต่ให้เข้าเฉพาะ agent ที่จ่ายค่าใช้ข้อมูล สำหรับบางบริษัท สิ่งที่ agent มาอ่านคือของที่ขายได้

**สี่ ระบบกันบอทที่มีอยู่แล้ว** ข้อนี้น่าสนใจที่สุด เพราะบางทีเว็บไม่ได้ตั้งใจบล็อก agent เลย Chris Canal ซีอีโอของ EquiStamp บริษัทประเมินความปลอดภัย AI อธิบายกับ The Verge ว่ามีระบบหลายอย่างที่ตั้งไว้เพื่อกันบอทหรือโปรแกรมที่พยายามหลอกลวงหรือเจาะระบบ และ AI agent ไปสะดุดระบบเดียวกันนั้น The Verge ยกตัวอย่างรายงานบน Reddit ว่า Google บล็อกบางบัญชีที่ใช้ Muse เพราะ "กิจกรรมน่าสงสัย" และบางคนมีปัญหาตอนจ่ายเงินบน Walmart ทั้งที่ Walmart เป็นพันธมิตรของ Meta

นอกจากนี้ Cloudflare บริษัทโครงสร้างพื้นฐานเว็บที่อยู่หลังเว็บไซต์จำนวนมาก ก็มีบทบาท หลังเปิดปุ่มบล็อกบอทเก็บข้อมูลของ AI ในคลิกเดียวเมื่อปี 2025 Cloudflare เริ่มบล็อกบอทที่เก็บข้อมูลเว็บไปใช้ทั้งทำดัชนีค้นหาและเทรน AI ในคราวเดียว

## ฝั่งบริษัท AI ตอบยังไง

Meta ตอบเรื่องเว็บบล็อก Muse ในโพสต์ต้นเดือนนี้ว่า การไล่ agent ส่วนตัวกลับ คือการไล่ลูกค้าที่อยู่ข้างหลังมันกลับไปด้วย และบอกว่าอยากทำงานร่วมกับธุรกิจเพื่อแก้ข้อกังวลมากกว่า ในทางปฏิบัติ Meta ไม่สู้กับ Amazon ตรง ๆ แต่ไปจับมือกับร้านค้าปลีกอย่าง Walmart, Gap, Sephora และ Best Buy ให้ Muse ซื้อของในเว็บเหล่านี้ได้ ส่วน Shopify ก็เปิดเครือข่ายหน้าร้านของตัวเองให้ AI agent เข้าได้

ด้าน Elon Musk เจ้าของ xAI ตอบเรื่อง Amazon ว่าบางทีเขาควรเปิดคู่แข่งของ Amazon เสียเอง ส่วน OpenAI กับ Google ยังไม่ได้ตอบ The Verge และ Instinct ปฏิเสธจะให้ความเห็น

## ทำไมเรื่องนี้สำคัญกว่าที่เห็น

Chris Canal ชี้ประเด็นที่ตรงที่สุดว่า คำขายของบริษัท AI คือ agent จะทำได้ทุกอย่างที่เราทำออนไลน์ได้ ถ้ามีบริษัทที่ตั้งใจทำให้มันทำไม่ได้ สิ่งที่ agent ทำได้จริงก็น้อยลง และนั่นกระทบมูลค่าที่คนมองบริษัท AI โดยตรง

อีกผลที่จะกระทบทุกคน แม้ไม่ได้ใช้ agent เลย คือ Canal มองว่าเว็บจะน่ารำคาญขึ้น เพราะเว็บจะเพิ่มด่านพิสูจน์ว่าคุณเป็นคน และเขาคาดว่าอาจลามไปถึงเว็บซื้อของชำธรรมดา ที่คุณต้องผ่านหลายด่านเพื่อยืนยันว่าเป็นคนจริง

## แปลว่าอะไรสำหรับคุณ

ส่วนนี้เป็นข้อสังเกตของเราจากข่าวข้างบน ไม่ใช่ข้อมูลจากแหล่งข่าว

**ถ้าคุณกำลังจะใช้ agent ทำธุระแทน** อย่าวางแผนงานสำคัญบนสมมติฐานว่า agent จะเข้าได้ทุกเว็บ งานที่ใช้ได้วันนี้อาจโดนบล็อกพรุ่งนี้ อย่างที่เกิดกับผู้ใช้ Cars.com และ Amtrak งานที่แตะบัญชีธนาคาร การจ่ายเงิน หรือการจองที่ยกเลิกยาก ให้ถือว่าเป็นงานที่คุณต้องทำเองหรืออย่างน้อยต้องเฝ้าดูขั้นสุดท้าย และถ้า agent บอกว่าทำไม่สำเร็จ สาเหตุอาจไม่ใช่ความผิดพลาดของมัน แต่เป็นเว็บปลายทางที่ไม่ยอมให้เข้า

**ถ้าคุณมีร้านหรือเว็บของตัวเอง** ข่าวนี้คือสัญญาณว่าอีกไม่นานคุณอาจต้องตัดสินใจเรื่องที่ไม่เคยต้องคิด ว่าจะต้อนรับลูกค้าที่ส่ง AI มาซื้อแทนไหม ตอนนี้วงการแบ่งเป็นสองทาง ฝั่งหนึ่งปิดหรือเก็บเงิน อย่าง Amazon, Delta และ Yelp อีกฝั่งเปิดรับ อย่างร้านที่จับมือกับ Meta และ Shopify ที่เปิดหน้าร้านให้ agent ถ้าเว็บของคุณอยู่หลังบริการอย่าง Cloudflare ควรรู้ว่ามีการตั้งค่ากันบอทอะไรเปิดอยู่บ้าง เพราะมันอาจกำลังกัน agent ของลูกค้าออกไปโดยที่คุณไม่ได้ตั้งใจ ยังเร็วเกินไปที่จะบอกว่าทางไหนถูก แต่การรู้ว่ามีการตัดสินใจนี้รออยู่ ดีกว่าโดนระบบตัดสินใจแทนโดยไม่รู้ตัว
