วันที่ 18 พฤศจิกายน 2026 TechCrunch รายงานว่าธนาคารใหญ่ในสหรัฐฯ อีกหลายแห่งออกมาบอกลูกค้าตรงกันว่า ถ้าคุณให้ AI agent เข้าบัญชีธนาคารของคุณ แล้วเกิดความเสียหาย คุณรับผิดชอบเอง รวมถึงกรณีที่ตัว agent ถูกแฮกด้วย

ข่าวนี้เกิดในสหรัฐฯ แต่สิ่งที่มันอธิบายเป็นเรื่องที่ทุกคนที่เริ่มใช้ AI agent ควรเข้าใจ คือ agent ที่ทำงานด้วยรหัสของคุณ ในสายตาของธนาคารก็คือตัวคุณ

## แต่ละธนาคารพูดอะไร

**Citi** ธนาคารพาณิชย์ใหญ่อันดับสามของสหรัฐฯ แก้ข้อตกลงผู้ใช้บริการออนไลน์ (Online User Agreement) ในสัปดาห์นี้ โฆษกของ Citi บอก TechCrunch ว่าต้องการให้ลูกค้าเข้าใจความเสี่ยงของการแชร์ข้อมูลล็อกอินธนาคาร หรือการอนุญาตให้เครื่องมือของบริษัทอื่นเข้าบัญชี และระบุว่าลูกค้าที่ให้ AI agent ของบริษัทอื่นเข้าบัญชี ต้องรับผิดชอบทุกกิจกรรมที่ทำผ่าน agent นั้น

ตามรายงาน ข้อตกลงใหม่ของ Citi ไปไกลกว่านั้นอีกขั้น ถ้าเครื่องมือ AI ทำข้อมูลล็อกอินรั่วหรือถูกแฮก สิ่งที่แฮกเกอร์ทำกับบัญชีก็เป็นความรับผิดชอบของลูกค้า ขณะที่ AI agent ที่ Citi ให้บริการเอง ลูกค้าใช้ได้โดยไม่มีภาระรับผิดเพิ่ม

**PNC** ธนาคารใหญ่อันดับแปด แก้ข้อตกลงในวันที่ 18 พฤศจิกายน

**Citizens** ส่งอีเมลถึงลูกค้าในสัปดาห์เดียวกัน เตือนว่าลูกค้าต้องรับผลของทุกอย่างที่ผู้ช่วย AI ทำ ตามอีเมลที่ TechCrunch ได้เห็น

**JPMorgan และ Bank of America** สองธนาคารใหญ่ที่สุดของประเทศ ประกาศนโยบายคล้ายกันตั้งแต่เดือนตุลาคม รายงานของ TechCrunch เมื่อ 27 ตุลาคมระบุว่า Bank of America ส่งอีเมลหัวเรื่อง "Protecting your finances in the AI World" ขอให้ลูกค้าอย่าแชร์ชื่อผู้ใช้และรหัสผ่านกับใครหรือบริการภายนอก รวมถึงเครื่องมือ AI หรือ agent ที่เสนอจะทำงานแทน และเขียนว่าถ้าแชร์ ลูกค้าต้องรับผิดชอบกิจกรรมที่เกิดจากการเข้าถึงนั้น โฆษกของธนาคารยืนยันว่าอีเมลนี้เป็นของจริง

## ทำไมธนาคารพูดเรื่องนี้ตอนนี้

AI agent รุ่นใหม่ ทั้งโมเดลจากบริษัท AI ใหญ่และแอปการเงินส่วนบุคคล ทำได้มากกว่าตอบคำถาม มันวิเคราะห์การใช้จ่าย ให้คำแนะนำ และจ่ายบิลหรือทำรายการแทนคุณได้ วิธีที่ง่ายที่สุดในการทำแบบนั้นคือให้ agent ถือรหัสผ่านธนาคารของคุณไว้

รายงานเดือนตุลาคมของ TechCrunch สรุปความเสี่ยงไว้สามข้อ

1. agent อาจทำรายการทางการเงินโดยที่คุณไม่รู้
2. ธนาคารอาจมองพฤติกรรมของ agent ว่าเป็นการลักลอบใช้บัญชี แล้วล็อกบัญชีคุณ
3. ถ้าบริการของ agent มีช่องโหว่ รหัสของคุณอาจรั่วไปถึงแฮกเกอร์ที่หวังเงิน

TechCrunch ยังชี้ว่าข้อตกลงบัญชีของธนาคารส่วนใหญ่ในสหรัฐฯ ให้ลูกค้ารับผิดชอบต่อคนที่ตัวเองให้ข้อมูลล็อกอินไปอยู่แล้ว สิ่งที่เปลี่ยนในรอบนี้คือธนาคารพูดถึง AI agent ตรง ๆ จนไม่เหลือที่ให้ตีความ และ TechCrunch ตั้งข้อสังเกตว่าธนาคารมองเครื่องมือการเงินจาก AI เป็นภัยแข่งขันต่อธุรกิจของตัวเองด้วย จึงไม่แปลกที่ Citi ยกเว้นภาระให้เฉพาะ agent ของตัวเอง

## เข้าใจกลไก: agent ที่ถือรหัส กับการเชื่อมแบบอ่านอย่างเดียว

นี่คือจุดที่คนใช้ AI ส่วนใหญ่มองข้าม การให้ AI เข้าบัญชีมีสองแบบที่ต่างกันมาก

**แบบที่ 1: agent ถือรหัสผ่านแล้วล็อกอินแทนคุณ** agent ประเภทที่คุมเบราว์เซอร์ได้จะเปิดหน้าเว็บธนาคาร พิมพ์ชื่อผู้ใช้กับรหัสผ่าน แล้วทำงานเหมือนคุณนั่งอยู่หน้าจอ ธนาคารแยกไม่ออกว่าใครกด ทุกปุ่มที่คุณกดได้ agent ก็กดได้ รวมถึงปุ่มโอนเงิน ถ้า agent เข้าใจคำสั่งผิด หรือเจอหน้าเว็บที่ฝังข้อความหลอกให้มันทำอย่างอื่น รายการนั้นก็ออกไปในชื่อคุณ

**แบบที่ 2: เชื่อมผ่านช่องทางที่ให้สิทธิ์จำกัด** ตัวอย่างคือ Personal Finance ของ Claude ที่ Anthropic เริ่มเปิดเบต้าเมื่อ 5 พฤศจิกายน สำหรับผู้ใช้แผน Pro, Max และ Ultra ในสหรัฐฯ ผู้ใช้เชื่อมบัญชีธนาคารและบัตรเครดิตผ่าน Plaid ซึ่งเป็นบริการตัวกลางเชื่อมข้อมูลการเงิน Anthropic ระบุว่า Claude เห็นได้แค่ชื่อธนาคาร ชื่อและประเภทบัญชี เลขบัญชีสี่ตัวท้าย ยอดคงเหลือ วงเงิน และรายการย้อนหลังไม่เกินสองปี และการเข้าถึงเป็นแบบอ่านอย่างเดียว ย้าย จัดการ หรือลงทุนเงินของคุณไม่ได้ Anthropic บอกด้วยว่าบทสนทนาในส่วนนี้ไม่ถูกใช้เทรนโมเดล

ความต่างของสองแบบนี้คือขอบเขตความเสียหายเมื่อเกิดเรื่อง แบบแรก ความผิดพลาดของ agent อาจกลายเป็นเงินที่ออกจากบัญชี แบบที่สอง ความผิดพลาดที่แย่ที่สุดคือคำตอบที่ผิด ซึ่งคุณยังตรวจได้ก่อนลงมือเอง

## ใช้ AI กับเรื่องเงินอย่างไรโดยไม่รับความเสี่ยงเกินจำเป็น

ข่าวนี้เป็นของธนาคารในสหรัฐฯ เราไม่ได้อ้างว่าธนาคารในไทยมีข้อตกลงแบบเดียวกัน แต่หลักคิดใช้ได้กับบัญชีของคุณ

- **อย่าส่งรหัสผ่านธนาคารให้ AI ตัวไหน** ไม่ว่าจะพิมพ์ลงแชต ใส่ในไฟล์ตั้งค่า หรือให้ agent จำไว้ล็อกอินแทน
- **ให้ AI ทำงานกับข้อมูลที่คุณดึงออกมาเอง** เช่น ดาวน์โหลด statement ลบเลขบัญชีเต็มออก แล้วค่อยให้ AI ช่วยจัดหมวดค่าใช้จ่ายหรือหาค่าธรรมเนียมแปลก ๆ คุณได้ประโยชน์ส่วนใหญ่โดยที่ AI แตะบัญชีจริงไม่ได้เลย
- **ถ้าจะเชื่อมบัญชี เลือกช่องทางที่อ่านได้อย่างเดียว** และอ่านให้ชัดว่าบริการนั้นเห็นข้อมูลอะไรบ้าง
- **ขั้นตอนที่ทำให้เงินออกจากบัญชี ให้คนกดเอง** ให้ AI เตรียมรายการ แต่การยืนยันโอนหรือจ่ายเป็นของคุณ
- **อ่านข้อตกลงบริการของธนาคารคุณ** โดยเฉพาะส่วนที่พูดถึงการให้บุคคลหรือบริการอื่นใช้ข้อมูลล็อกอิน ก่อนให้เครื่องมือใดแตะบัญชีการเงิน

AI agent มีประโยชน์จริงกับงานการเงินส่วนตัว แต่ข่าวรอบนี้บอกชัดว่าความเสี่ยงของมันไม่ได้หายไปไหน มันแค่ย้ายจากธนาคารมาอยู่ที่คุณ
